# Utils Directory README

## Overview

Shared utilities and blockchain integration helpers.

## Layout

-  `abis/` contract ABIs used by the frontend
-  `contractInit.ts` env-aware contract helpers (prod/dev)
-  `walletInit.ts` env-aware wallet initialization
-  `handleContractError.ts` error mapping for contract interactions
-  `methods/` app-level utility modules (ticket purchase, auth, email)
-  `prod/uris/` artifact metadata used by the UI
